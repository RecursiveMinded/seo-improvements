# Master foundation checklist

Apply to every project. Copy into the project file's Status section and tick items there.

- [ ] Google Search Console verified, sitemap submitted
- [ ] Bing Webmaster Tools verified (import from GSC), sitemap submitted
- [ ] IndexNow key installed, pings on publish/update
- [ ] robots.txt reviewed; no accidental noindex
- [ ] Schema: Organization/WebSite site-wide, plus page-type schema (Article, FAQ, SoftwareApplication, LocalBusiness as fits)
- [ ] Topical hub per app: one hub page linking all supporting pages, supporting pages linking back
- [ ] Core Web Vitals pass (LCP, INP, CLS) on mobile for key templates
- [ ] People-first content: first-hand experience, named author with credentials, sources cited (E-E-A-T)
- [ ] Titles and meta descriptions written for revenue-intent queries
- [ ] Conversion tracking tied to money (signup, lead, sale)
